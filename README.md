# Spring Portfolio

## 概要
Springで作成したDVDレンタルシステムのポートフォリオアプリです。<br>
DVDのレンタル・返却や、ユーザー管理機能を実装しています。

## アカウント
- 管理者<br>
	ユーザー名：admin<br>
	パスワード：pass
- 一般ユーザー<br>
	ユーザー名：user<br>
	パスワード：pass

※実運用は想定していないため、分かりやすさ重視の観点から<br>上記のアカウントを用意しております。

## 機能
- ログイン機能
- DVDレンタル
- DVD返却
- ユーザー管理
- 権限による機能・表示制限
- ログアウト

## 技術
- Java
- Spring Boot
- Thymeleaf
- MyBatis
- Spring Security
- PostgreSQL
- HTML / CSS
